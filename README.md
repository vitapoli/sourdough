# Sourdough — трекер закваски для домашних пекарей

Первое русскоязычное веб-приложение для тех, кто печёт хлеб на закваске.

Закваска как живой питомец: кормите, следите за настроением, наблюдайте за подъёмом в реальном времени.

## Возможности

**Трекер закваски**
- Ведение нескольких заквасок одновременно
- «Настроение» закваски — визуальный индикатор состояния
- Анимированная баночка с прогнозом подъёма в реальном времени
- История кормлений с редактированием
- Настройка кривой брожения под свою закваску

**Калькулятор гидратации**
- Расчёт пропорций муки и воды
- Быстрый пересчёт под нужную гидратацию

**Рецепты**
- Встроенные рецепты (белый, ржаной, чиабатта, цельнозерновой)
- Добавление своих рецептов

## Стек

- **Next.js** (App Router) — фронтенд и бэкенд
- **React 19** — UI
- **Prisma** + **SQLite** — база данных
- **Tailwind CSS 4** — стили
- **TypeScript** — типизация

## Установка и запуск

```bash
# Установить зависимости
npm install

# Сгенерировать Prisma-клиент и применить миграции
npx prisma generate
npx prisma migrate deploy

# Заполнить базу начальными рецептами
npx prisma db seed

# Запустить dev-сервер
npx next dev --port 3000 --hostname 0.0.0.0
```

Приложение будет доступно по адресу `http://localhost:3000`.
