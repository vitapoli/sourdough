# Проект: Sourdough

## Что это
Веб-приложение для домашних пекарей, которые работают с хлебом на закваске.
Первое русскоязычное специализированное приложение в этой нише.

Три направления (в порядке приоритета):
1. **Трекер закваски** — ведение закваски как "тамагочи": подкормки, состояние, настроение, напоминания
2. **Рецепты** — рецепты хлеба на закваске
3. **Магазин** — объявления о продаже домашнего хлеба

## Ключевые фишки (дифференциация)
- "Тамагочи для закваски" — закваска как живой питомец с настроением
- Пошаговый мастер "Первая закваска за 7 дней" для новичков
- Паспорт закваски — QR-код с историей для передачи другу
- Привязка к температуре — умные подсказки по кормлению
- Фотожурнал — визуальная история закваски
- Всё в одном: трекинг + рецепты + таймеры + магазин

## Целевая аудитория
- MVP: домашние пекари и покупатели домашнего хлеба
- В будущем: пекарни и профессиональные пекари (архитектура должна позволять расширение)

## Конкуренты
- Русскоязычных аналогов нет
- Англоязычные: Sourdough Forge (iOS), Rise (iOS), Loaflo (iOS) — все только мобильные и только iOS
- На Android и вебе — практически пусто

## Стек
- **Next.js** (App Router) — фронтенд + бэкенд
- **SQLite** + **Prisma** — база данных
- **Tailwind CSS** — стили
- **TypeScript** — язык

## Дизайн
- Стиль: тёплый, крафтовый, уютный
- Цвета: тёплые натуральные тона (беж, коричневый, кремовый, терракота)
- Скруглённые формы, мягкие тени
- Закваска-персонаж с эмоциями в центре главного экрана
- Mobile-first: удобно на телефоне с мокрыми/мучными руками (большие кнопки)

## Подход
- MVP: минимум функций, но рабочий продукт
- Этап 1: трекер закваски (персональный инструмент пекаря)
- Этап 2: рецепты хлеба
- Этап 3: магазин объявлений (с контактами продавца, без онлайн-оплаты)
- Оплату можно добавить позже, когда станет понятно что нужно
